ชุดไฟล์แอป ระบบบันทึกรอบเดือนสตรี (สร้างเมื่อ 20261028-130002)
แอปนี้คือหน้าจอของระบบฉบับเต็ม เข้าสู่ระบบและบันทึกข้อมูลได้ในแอปโดยตรง โดยส่งข้อมูลไปยังระบบ Apps Script ผ่านลิงก์ Web App

ก่อนอัปโหลด: ระบบ Apps Script ต้องเป็นเวอร์ชัน 1.1.0 ขึ้นไป (ดูเลขเวอร์ชันที่ด้านล่างหน้าเข้าสู่ระบบของเว็บ)
และ Deploy ไว้แบบ Execute as: Me / Who has access: Anyone

วิธีติดตั้งบน GitHub Pages (ฟรี)
1. เข้า github.com กด New repository ตั้งชื่อ เช่น period-app เลือก Public แล้วกด Create repository
2. กด uploading an existing file (หรือ Add file > Upload files) ลากไฟล์ทั้งหมดในชุดนี้ (ไม่ใช่ไฟล์ zip) ไปวาง แล้วกด Commit changes
3. ไปที่ Settings > Pages > Build and deployment > Source เลือก Deploy from a branch เลือก main และ /(root) แล้วกด Save
4. รอประมาณ 1-10 นาที ลิงก์แอปจะเป็น https://ชื่อบัญชี.github.io/period-app/
5. นำลิงก์นั้นไปบันทึกในระบบ: หน้าผู้ดูแล > แอปบนมือถือ (PWA) > ลิงก์ของแอป (ใช้กับปุ่ม Google และลิงก์ตั้งรหัสผ่านใหม่ให้กลับเข้าแอป)
6. ถ้าใช้ปุ่มเข้าสู่ระบบด้วย Google ให้เพิ่มลิงก์แอปเป็น Authorized redirect URI ใน Google Cloud Console ด้วย

อัปเดตแอปภายหลัง: เมื่ออัปเดตโค้ดระบบหรือเปลี่ยนโลโก้ ให้สร้างชุดไฟล์ใหม่ แล้วอัปโหลดทับไฟล์เดิมทั้งหมด (ลิงก์แอปไม่เปลี่ยน)
